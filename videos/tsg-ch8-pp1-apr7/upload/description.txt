T.S. Grewal Class 11 (CBSE, 2025–26 edition) · Chapter 8: Journal · Practical Problem 1 · Page 8.57
Transaction: 2023, April 7 — Goods returned to Pankaj ₹12,000

✅ JOURNAL ENTRY
Date: 2023, April 7
Pankaj A/c … Dr. 12,000
   To Purchases Return A/c 12,000
(Being goods returned to Pankaj)

📘 STEP-BY-STEP EXPLANATION
On April 3, the business bought goods from Pankaj on credit for ₹18,000 — so we owed Pankaj ₹18,000.
On April 7, goods worth ₹12,000 are sent back to Pankaj.
1️⃣ Goods go OUT of the business back to the supplier → this is a PURCHASES RETURN (also called RETURN OUTWARD).
2️⃣ Pankaj RECEIVES the goods → his account is debited.
After this entry, we owe Pankaj only ₹18,000 − ₹12,000 = ₹6,000.

📏 RULES APPLIED
• Pankaj A/c — Personal Account; Pankaj is the receiver → "Debit the receiver"
• Purchases Return A/c — goods go back → Credit
Modern approach: Creditor (liability) decreases → Debit; Purchases Return increases → Credit.

⚠️ COMMON MISTAKES STUDENTS MAKE
✗ Crediting "Purchases A/c" directly — T.S. Grewal uses a separate Purchases Return A/c.
✗ Writing "Goods A/c" — never use Goods A/c in the journal.
✗ Debiting Cash A/c — no cash is involved; we simply owe Pankaj less.
✗ Mixing up the names: Purchases Return = Return Outward; Sales Return = Return Inward.
